# Aditi Jha — Professional Portfolio

A responsive, static portfolio website built with HTML, CSS, and JavaScript. No build tools or coding are needed to preview it.

## Preview on your computer
1. Extract `aditi_jha_portfolio.zip`.
2. Open the extracted `aditi_jha_portfolio` folder.
3. Double-click `index.html` to open the site in your browser.

## Publish for free with GitHub Pages
You already have a GitHub profile: https://github.com/aditijha2804

1. Sign in to GitHub.
2. Open your profile and click **Repositories**, then **New**.
3. Name the repository exactly `aditijha2804.github.io`.
4. Set it to **Public**, then create the repository.
5. In the new repository, choose **Add file → Upload files**.
6. Open the extracted website folder on your computer and upload the *contents* of that folder: `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder. Do not upload only the ZIP file.
7. Scroll down and click **Commit changes**.
8. Open **Settings → Pages**. If asked for a publishing source, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
9. Wait a few minutes and open `https://aditijha2804.github.io/`.

GitHub's menus may vary slightly. If the site doesn't appear immediately, wait a few minutes and check the Pages settings/build status.
